# omarchy-asus.github.io

The [omarchy-asus](https://omarchy-asus.github.io) landing page: what you get on an ASUS laptop,
measured numbers, packages, and links into the [hub repo](https://github.com/omarchy-asus/omarchy-asus).

`index.html` is generated. Edit `src/template.html` (copy), `src/charts.py` (chart data) or
`src/wordmark.py`, then run `make -C src`.

Every number on the page comes from a measurement on a ROG Zephyrus G16 GA605KM. If a number
has no measurement behind it, it doesn't go on the page. Say what the conditions were.
